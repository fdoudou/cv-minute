# CV-Minute

An easy to use and fullstack MERN app to help people build their CV/resumes.

![Version](https://img.shields.io/badge/version-1.0.0-green.svg) ![Node](https://img.shields.io/badge/node-%3E%3D14.0.0-brightgreen.svg)

## Features

- Various templates
- Account and dashboard
- Feature-rich CV editor
- AI generator/reviewer/editor
- Multiple CV/resumes

### Tech Stack

- **JavaScript**
- **Node.js**
- **React**
- **express**
- **HTML/CSS**
- **Mysql**
